# 週案＆時数管理ノート（every_week_schedule）

小学校の学級担任向けの、週案（時間割・単元・連絡・指導記録）と年間の授業時数を管理する Google Apps Script のウェブアプリです。
クイックノート（フォルダ分け・添付）、時間割の印刷、時数集計、Gemini 向けプロンプト生成、バックアップの書き出し・読み込みができます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | Apps Script 側。ドライブ上の JSON ファイルへの読み書き、旧データの移行、添付ファイルの保存、ドライブ検索 |
| `index.html` | 画面側。HTML・CSS・JavaScript をひとつにまとめたシングルページ |
| `test/server.test.js` | `Code.gs` のロジックを GAS サービスのモックで検証する Node のテスト |
| `test/browser.test.js` | `index.html` を Playwright で動かして主要な流れを検証するテスト |

## デプロイ手順

1. Google Apps Script で新しいプロジェクトを作り、`Code.gs` と `index.html` の内容をそれぞれ同名のファイルとして貼り付けます。
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選びます。
3. **「次のユーザーとして実行」は「ウェブアプリケーションにアクセスしているユーザー」** にしてください。
   利用者それぞれの Google ドライブにデータを保存する設計のため、この設定でないと利用者を特定できず、読み書きをエラーで止めます。
4. 「アクセスできるユーザー」は用途に合わせて選びます（自分だけ、組織内、Google アカウントを持つ全員）。
5. 表示された URL を開き、初回はドライブへのアクセスを承認します。

## データの保存場所と仕組み

- データは利用者のドライブ直下の `weekly_plan_data_<メールアドレス>.json` に、時間割・ノート・設定をまとめて保存します。
- ファイルには版番号（`meta.revision`）が入っています。保存時に版番号が食い違っていれば上書きせず、画面側がサーバーの最新にこちらの変更分だけを重ねて保存し直します。複数端末で開いていても、どちらかの入力が黙って消えることはありません。
- 保存は変更のたびに自動で行われます（連続した変更はまとめて送信）。通信に失敗し続けた場合は変更を端末内に一時保存し、次回起動時に復元を案内します。
- 添付ファイルはドライブの `週案アプリ_添付ファイル` フォルダに保存されます。公開共有は行いません。
- 設定画面の「データのバックアップ」から、すべてのデータを JSON ファイルとして書き出し・読み込みできます。

## 旧バージョンからの移行

初回の読み込み時に、旧バージョンの保存先（`weekly_plan_data.json`、`週案アプリ_保存データ.json`、バインド済みスプレッドシートのセル）を一度だけ探して取り込みます。
移行は一度きりで、以後はアプリ上でデータを消しても旧データが戻ることはありません。
手動で取り込みたいときは GAS エディタで `migrateSpreadsheetToDrive()` を実行してください。中身を確認するには `inspectSpreadsheetData()` を実行し、ログを見ます。

## テストの実行

```bash
# Apps Script 側のロジック（追加インストール不要）
node test/server.test.js

# 画面側（Playwright と Chromium が必要）
npm i -D playwright && npx playwright install chromium
node test/browser.test.js
```

## 開発メモ

- 画面側はビルド不要の素の HTML/JavaScript です。`index.html` を直接開いても動きますが、Google のバックエンドが無いため保存はされません（画面下に「ローカルのため保存されません」と表示されます）。
- Gemini 連携は「プロンプトをコピーして貼り付ける」方式です。アプリのデータが外部の API に送信されることはありません。
